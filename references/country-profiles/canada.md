# 加拿大

## 比较范围

仅比较学历型本科、硕士、博士和成人学位教育路径；不推荐具体院校、专业或城市。

## 决策维度

- 学历路径与申请门槛
- 成本与资金
- 学业体验
- 职业结果与长期发展
- 生活融入
- 适配与排斥
- 风险与证据

## 初筛重点

- 对照用户的总预算、目标学历、语言、就业和长期发展目标。
- 将省份、学习项目和用户身份相关差异视为需实时核验的变量。
- 对研究路径优先核验资助、研究匹配和申请时间窗口。

## 本次必须核验

- 学习许可、兼职和毕业后工作相关规则；
- 目标路径的官方招生、语言、费用和资助信息；
- 与省份、用户身份或家庭安排有关的限制；
- 影响预算或长期发展判断的官方信息。

## 官方检索优先级

1. 加拿大移民、难民及公民部门的信息；
2. 加拿大官方国际教育信息；
3. 目标院校的招生、费用、奖学金和研究资助页面；
4. 加拿大官方统计与省级公开资料。

## 待证实假设

仅在本次官方核验后，判断加拿大是否满足用户的预算、项目、就业与长期发展条件。
