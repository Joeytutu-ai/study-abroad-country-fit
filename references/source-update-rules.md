# 时效与证据规则

## 证据层级

1. **官方移民/签证政策：**用于入境、签证、兼职、毕业后工作和身份路径判断。
2. **官方教育或院校信息：**用于学制、课程、语言、申请窗口和资助判断。
3. **官方公开统计：**用于公开成本、行业或教育统计的背景判断。
4. **经验判断：**只能解释生活适应或定性取舍，必须明确标为经验判断，不能推翻前三级证据。

## 本次运行的核验规则

- 对影响结论的可变事实，优先检索官方页面；记录页面标题、链接、来源类型与核验日期。
- 官方页面与旧画像冲突时，以本次官方页面为准。
- 无法核验时写“无法核验”，不编造期限、金额、录取率、就业率或资格结论。
- 不将第三方排行榜、社交帖子、营销内容或单一个案作为政策、成本或就业结论的唯一依据。
- 只检索可能进入Top3的目的地和需解释硬性排除的目的地，避免无关的全量资料搜集。

## 必须实时核验的项目

- 签证、入境与身份要求；
- 学生兼职权限和毕业后工作路径；
- 目标学历路径的官方入学、语言和资助信息；
- 用户预算中会改变可行性的官方费用信息；
- 用户身份、家庭需求或研究资助所涉及的特殊限制。
